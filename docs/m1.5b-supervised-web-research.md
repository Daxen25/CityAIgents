# M1.5B supervised public web Researcher

## Architecture and provider choice

Requirements Brief retains the input-only Gemini path, existing schema and optional 503 retry. Web Research is a separate, explicitly selected mode: **one Tavily Search API basic request**, at most five provider excerpts, then **one Gemini structured synthesis**. No Gemini grounding tools or URL fetching are enabled. This reuses Gemini's working structured-output transport while keeping search evidence independent of model-generated URLs.

Dedicated search was chosen over Gemini Google Search grounding: provider excerpts can be captured before synthesis and tested independently, citations can be validated against that exact set, and the request budget is explicit. Grounding would couple tool availability, structured output and citation metadata to the configured model; those capabilities have not been verified for this project. Tavily is an additional credential and potentially billable service, not assumed free. Relevant provider contracts: [Tavily Search](https://docs.tavily.com/documentation/api-reference/endpoint/search), [Gemini structured output](https://ai.google.dev/gemini-api/docs/structured-output), [Gemini search grounding](https://ai.google.dev/gemini-api/docs/google-search). The public [official Tavily Python SDK](https://github.com/tavily-ai/tavily-python/blob/master/tavily/tavily.py) was inspected to confirm the fixed API base, Bearer header and explicit basic/max-results/auto-parameters options. All development/provider tests use mocks; live account/model compatibility and pricing remain deployment prerequisites.

## Authorization and history

`authorize_researcher_execution_v2` locks mission then task, requires current workspace ownership, fresh consent, an approved AI mission and approved Researcher assignment. Original tasks retain the original plan review and decision-snapshot checks. Extension tasks require the immutable approved proposal, a review decided by the **executing current owner**, acceptance of that exact position and matching title/deliverable/Researcher role. Another owner cannot reuse that review. No rejected/stale/unreviewed proposal is executable. Developer and Chief of Staff remain unavailable.

The authorization stores mode and fixed budget (brief: zero searches/up to two Gemini requests; web: one search/one synthesis). Trusted start and finalization revalidate owner, assignment, origin, capability and lease. Old authorization RPC means brief only. Old finalizers reject web runs. Three authorizations per task, one running mission attempt, 120-second lease, recovery, atomic artifact persistence and explicit human accept/reject remain. Failed calls consume the authorized attempt. No counter resets. Rejected deliverables remain terminal under the existing lifecycle.

Extension task content/assignment/provenance remain frozen; only execution status/run reference can change through existing privileged transitions. Authorizations and Researcher artifacts are immutable. Existing task/run/artifact/review rows are retained; new mode columns default to brief. Artifacts retain task/run/mission/workspace links; extension origin resolves through the immutable task and authorization review link. Accepted report summaries already enter M1.5A's existing bounded context snapshot (last five accepted summaries, 500 characters each), with no follow-up task or agent invocation.

## Search security and budgets

- Fixed HTTPS `api.tavily.com/search`, header credential, redirects disabled. No caller-controlled host or endpoint.
- One query from task title + mission objective, truncated to 600 characters. Basic depth, five results, no answer/raw pages/images/automatic parameter escalation. Zero retries/fallbacks.
- Search timeout at most eight seconds; streamed response at most 48,000 bytes. Total search+synthesis at most 30 seconds and within existing action deadline; finalization reserve remains unchanged. One candidate, 4,000 output tokens. No separate web retry even when the brief 503 retry flag is enabled.
- Reports are capped at 44,000 compact JSON bytes before finalization (below SQL’s 48,000-byte JSONB limit, reserving serialization overhead). At most five unique sources, 300-character title and 2,000-character excerpt each. Only public-looking HTTPS DNS URLs, no userinfo/nonstandard ports/IP literals/local/metadata names. URLs are normalized with fragments removed, not asserted to be publisher-declared canonical URLs.
- **No source URL is fetched by Agent City**, so provider evidence cannot cause application SSRF, DNS rebinding or redirect traversal. DNS resolution/destination safety of a user's later browser click is not independently verified. Provider crawling is governed by its public-search service. No authenticated website access is requested.
- Source text is untrusted data. Fixed synthesis instructions prohibit following embedded commands. No model tools, shell, filesystem, email, repository writes or delegation. Prompt-injection resistance cannot guarantee model truthfulness; human review remains mandatory.
- Logs contain only allowlisted operation stage, HTTP status/classification, counts, timing and IDs; no raw responses, prompts, documents, source text, keys or lease hashes. Search errors never trigger synthesis; ambiguous persistence never triggers another provider call.

The strict report includes objective, summary, findings (source excerpts versus model inference), references, assumptions/unverified assertions, conflicts/incompleteness, open questions, recommendations and limitations. Sources are attached by the server, never supplied by Gemini. Every source reference must match the saved IDs; inference has no citations. TypeScript and SQL validate shape, sizes, URLs and reference consistency. Retrieval timestamps mean **provider evidence collected by this application**, not page publication or independent retrieval verification. Presence in search results and human acceptance do not verify factual accuracy or claim entailment.

1. Confirm `main` includes M1.5A. Verify remote tables/functions against local M1.3–M1.5A definitions; historical version IDs differ and M1.2 was applied manually. Stop on drift. Do not run `supabase db push`, replay history or reconcile version IDs.
2. Review/apply **only** `supabase/migrations/20261023160000_supervised_web_research.sql` as one atomic tracked migration. Check origin/budget constraints, RLS, owner-only v2 authorization, service-only web finalizer, immutable artifacts/authorization and extension task guard. Confirm no prior data/attempts changed. This repository does not execute remote migrations.
3. Keep `AGENT_CITY_RESEARCHER_WEB_ENABLED=false` through deployment prerequisites. Server-only values: `TAVILY_API_KEY`, `GEMINI_API_KEY`, `SUPABASE_SERVICE_ROLE_KEY`; existing Supabase URL/publishable configuration stays unchanged. Keep `AGENT_CITY_RESEARCHER_EXECUTION_ENABLED=true` only where supervised Researcher use is authorized. `GEMINI_MODEL=gemini-3.6-flash` is the user-reported working model, still requiring project-specific compatibility verification; no application model default is changed here. `AGENT_CITY_RESEARCHER_503_RETRY_ENABLED` affects brief only, default false. Planning/extension flags remain independent.
4. Verify Tavily account access, current basic-search pricing, Gemini model structured-output support and both accounts' quota/rate/spend controls manually. There is no per-workspace monetary cap or global rate limiter introduced here; fixed per-run limits plus three attempts are not a currency budget. Choose provider-side caps before enabling. No live diagnostic is run by tests/build.
5. After authorized deployment and schema verification, set the dedicated web flag true. Missing search credentials keep UI web mode unavailable and server execution fails before authorization/provider calls. Never prefix keys with `NEXT_PUBLIC_`.
6. As the owner who approved its extension, find the existing task **“Analisi della presenza online della concorrenza locale”**. Confirm immutable accepted Researcher assignment and remaining attempts. Do not create missions or reset attempts. Choose Web Research; read Tavily/model/one-search/one-synthesis/cost/external-query notice, then explicitly authorize once. This is the only requested hosted test and is **not performed in development**.
7. Expect one search, at most five evidence sources, one synthesis, model provenance, elapsed time and a pending-review artifact linked to the same task/run/mission/workspace. Inspect public links and quoted excerpts manually; confirm findings reference saved source IDs, inference is marked, and gaps/conflicts are explicit. Do not accept fabricated business facts or treat provider excerpts as independent verification.
8. Explicitly accept or reject. Verify audit events and history; acceptance must not create another run, task or agent call. Check member/other-workspace denial and unchanged input-only planning/Researcher/mock behavior. If interrupted, wait for the existing two-minute lease and recover; do not automatically retry.

## Rollback

Disable `AGENT_CITY_RESEARCHER_WEB_ENABLED` immediately to prevent new web authorizations. If needed disable `AGENT_CITY_RESEARCHER_EXECUTION_ENABLED` to stop all new Researcher runs. Existing review/recovery and saved reports remain available. Let in-flight requests complete or recover after lease expiry; disabling a flag does not cancel a request already sent. Keep the additive schema and audit history; never delete artifacts/authorizations or reset attempts. Prefer reverting the application with flags disabled; old UI cannot preview web reports, so review them with the updated application before reverting. Do not drop the migration or replay historical versions.
